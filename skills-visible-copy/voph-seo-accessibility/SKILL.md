# voph-seo-accessibility

## Required context

Before acting, read:

- `CLAUDE.md`
- `references/voph-project-brief.md`

If the repository has existing code, inspect it before editing.

## Non-negotiables

- The audience is B2B professionals, not consumers.
- The website is one-page unless instructed otherwise.
- The style is dark, premium, minimalist, spacious and modern.
- Copy must be short and confident.
- Do not invent contact data, certifications, legal claims or specific business relationships.
- Avoid AI-generated people, handshake imagery, cheap stock-photo style and generic FMCG web design.


## Accessibility checklist

Check and fix:

- one clear h1,
- logical heading hierarchy,
- semantic sections,
- accessible buttons and links,
- keyboard navigation,
- focus visible states,
- contrast,
- alt text,
- form labels,
- tap target sizes,
- reduced motion support.

## SEO checklist

Check and fix:

- page title,
- meta description,
- Open Graph title and description,
- structured section content,
- meaningful anchor text,
- no fake claims,
- relevant B2B keywords used naturally.

## Target keywords

Use naturally where appropriate:

- FMCG trading,
- FMCG sourcing,
- FMCG distribution,
- global brands,
- wholesale sourcing,
- retail sourcing,
- long-term trading partner.

## Output

Make fixes and summarize exactly what changed.
