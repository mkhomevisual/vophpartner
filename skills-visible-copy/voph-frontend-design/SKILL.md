# voph-frontend-design

## Required context

Before acting, read:

- `CLAUDE.md`
- `references/voph-project-brief.md`

If the repository has existing code, inspect it before editing.

## Non-negotiables

- The audience is B2B professionals, not consumers.
- The website is one-page unless instructed otherwise.
- The style is dark, premium, minimalist, spacious and modern.
- Copy must be short and confident.
- Do not invent contact data, certifications, legal claims or specific business relationships.
- Avoid AI-generated people, handshake imagery, cheap stock-photo style and generic FMCG web design.


## Role

Act as a senior frontend designer and frontend implementation partner.

## Design target

Create a premium dark one-page B2B website for a modern FMCG trading and sourcing company.

The design should feel:

- confident,
- international,
- precise,
- spacious,
- practical,
- trustworthy,
- 2026-ready.

## Required sections

1. Navigation.
2. Hero.
3. About.
4. Services.
5. Brand / product cooperation strip.
6. Why VOPH Partners.
7. Process / partnership model.
8. Logistics credibility visual.
9. Contact CTA.
10. Footer.

## Visual rules

Prefer:

- dark background,
- light typography,
- large headlines,
- narrow premium accent color,
- subtle gradients,
- thin borders,
- soft surface contrast,
- clean cards,
- logistics-inspired linework,
- icons with consistent stroke,
- strong CTA hierarchy.

Avoid:

- generic SaaS template look,
- stock-photo hero with business people,
- loud colors,
- overdesigned animations,
- too many cards,
- dense paragraphs.

## Implementation rules

- Inspect the stack before editing.
- Use existing conventions.
- Prefer reusable components.
- Use tokens for colors, spacing and type.
- Keep responsive behavior mobile-first.
- Add accessible focus states.
- Do not add heavy dependencies unless justified.
- Run validation commands where available.

## Output

Before editing, state a concise plan.

After editing, summarize:

- files changed,
- design decisions,
- commands run,
- remaining placeholders.
