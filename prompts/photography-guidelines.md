# Photography Guidelines Prompt

## Use this when

You need image direction or asset sourcing criteria.

## Prompt

```text
Read CLAUDE.md and references/voph-project-brief.md.

Create photography and visual asset guidelines for the VOPH Partners website.

Prefer:
- real logistics photos,
- warehouses,
- containers,
- trucks,
- ports,
- pallets,
- supply chain,
- FMCG product and packaging details,
- abstract close-ups if real photos are unavailable.

Avoid:
- people posing at camera,
- handshake photos,
- AI-generated people,
- artificial corporate style,
- cheap stock images.

Return:
- visual themes,
- do/don’t list,
- prompt ideas for temporary abstract visuals,
- alt-text guidance,
- where each image type belongs on the page.
```
