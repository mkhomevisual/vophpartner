# Start Here – First Claude Code Prompts

Use these prompts in order.

## 1. Inspect before editing

```text
Read CLAUDE.md and references/voph-project-brief.md. Inspect the repository structure, package files and existing frontend stack. Do not edit files yet. Return: current stack, likely entry files, risks, and a step-by-step implementation plan for a premium one-page VOPH Partners website.
```

## 2. Create design system first

```text
Use the VOPH project brief. Create or update the frontend design system: color tokens, typography scale, spacing scale, containers, section rhythm, button styles, card styles and responsive rules. Keep the look dark, premium, minimalist and B2B. Do not implement page sections yet unless the project structure requires it.
```

## 3. Build the one-page landing page

```text
Implement the VOPH Partners one-page website using the existing stack. Required sections: nav, hero, about, services, why VOPH, brand strip, partnership/process, logistics credibility visual, contact CTA and footer. Keep copy concise, avoid stock-photo clichés, and use placeholders for missing contact data.
```

## 4. Polish responsive design

```text
Review the page at mobile, tablet, laptop and large desktop breakpoints. Fix spacing, typography, overflow, touch targets, CTA hierarchy and readability. Keep the visual system consistent and premium.
```

## 5. Accessibility, SEO and final QA

```text
Audit the website for semantic HTML, heading hierarchy, keyboard focus, contrast, link labels, form labels, meta title, meta description, Open Graph basics and build errors. Fix issues and report exactly what changed.
```
