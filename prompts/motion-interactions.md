# Motion and Interaction Prompt

## Use this when

You need subtle animations and microinteractions.

## Prompt

```text
Read CLAUDE.md and references/voph-project-brief.md. Inspect the frontend stack.

Add subtle premium motion to the VOPH Partners website.

Good motion:
- nav hover states,
- CTA hover/press states,
- card lift or border glow,
- slow background gradient movement,
- scroll reveal with reduced-motion fallback,
- logistics line/path accent animation.

Avoid:
- bouncing,
- aggressive parallax,
- loud transitions,
- motion that feels like a startup template,
- animation that hurts readability.

Respect prefers-reduced-motion. Keep performance clean. Do not add animation libraries unless the project already uses one or there is a strong reason.
```
