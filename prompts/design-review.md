# Design Review Prompt

## Use this when

You need Claude Code to review its own output like a strict art director.

## Prompt

```text
Read CLAUDE.md, references/voph-project-brief.md and inspect the current page implementation.

Review the website like a strict senior art director.

Score from 1–10:
- premium B2B feel,
- clarity,
- visual hierarchy,
- spacing,
- typography,
- mobile quality,
- CTA strength,
- originality,
- brief alignment,
- trustworthiness.

Then fix the highest-impact issues. Do not overcomplicate the design. Keep the VOPH tone: modern, minimalist, reliable, long-term oriented.
```
