# Design Guidelines Prompt

## Use this when

You need design direction before generating or reviewing UI.

## Prompt

```text
Read CLAUDE.md and references/voph-project-brief.md.

Create a practical design guide for this website.

Include:
- color palette,
- typography scale,
- layout grid,
- spacing rhythm,
- section structure,
- card style,
- button style,
- icon style,
- photo/visual direction,
- motion direction,
- mobile rules,
- what to avoid.

The visual result must feel like a modern 2026 FMCG trading company:
dark, premium, minimalist, reliable and international.

Return a concrete guide that a frontend developer can implement.
```
