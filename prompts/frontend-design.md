# Frontend Design Prompt

## Use this when

You need Claude Code to design and implement the frontend with strong visual taste.

## Prompt

```text
Read CLAUDE.md and references/voph-project-brief.md. Then inspect the current frontend stack.

Act as a senior frontend designer and implementation partner.

Design and implement a premium one-page VOPH Partners website with this direction:
- dark editorial corporate look,
- large confident typography,
- strong whitespace,
- subtle gradients,
- thin borders,
- modern logistics-inspired linework,
- clean cards,
- clear B2B CTA flow,
- no generic template feel.

Required sections:
1. navigation with anchor links,
2. hero with primary and secondary CTA,
3. about,
4. services,
5. brand/product cooperation strip,
6. why VOPH Partners,
7. process / partnership model,
8. logistics credibility visual,
9. contact CTA,
10. footer.

Implementation rules:
- Use the existing stack and conventions.
- Do not add heavy dependencies unless necessary.
- Keep components reusable.
- Use design tokens for colors, spacing and typography.
- Ensure mobile-first responsive layout.
- Ensure keyboard focus states and semantic headings.
- Use placeholders for missing phone/email/meeting link.
- Run build/lint/typecheck if available.

Before editing, provide a compact plan. After editing, summarize files changed and commands run.
```
